# Experimental assets (not production)

These files were generated during Phase 2-A but **do not match** the
required clean modern pixel-art art direction (soft illustrated / non-hard-pixel).

They are kept for style review only. The Asset Resolver does **not** load them.

Production Office visuals currently use improved SVG/CSS until true pixel PNGs
are supplied under the paths listed in `assets-manifest.json`.
