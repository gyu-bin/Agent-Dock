# sprite-gen (Agent Deck)

Isolated asset-generation tool — not part of Agent Deck runtime.

## Install

```bash
cd tools/sprite-gen
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
sprite-gen --help
```

Upstream: https://github.com/aldegad/sprite-gen (Apache-2.0)

## Role atlas (shipped)

| Role | Path | States |
|------|------|--------|
| developer | `client/public/assets/sprites/roles/developer/` | idle, walk-*, work (body-only), talk |

`work` must never bake desk/laptop — furniture is a separate PNG layer.

## Expanding roles

Planned: pm, game-designer, designer, researcher, marketer, tester, manager.

Do not generate 279 unique sprites. Use Role Base + `sprite-gen recolor` later.

Copy atlas to `client/public/assets/sprites/roles/{role}/` and register in `roleSprites.ts`.

## Furniture PNG

Not generated by sprite-gen. Drop packs into `client/public/assets/furniture|plants|environment/` and `registerProductionPng`.
